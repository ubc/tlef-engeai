Welcome to Monitor Dashboard

Review course activity without treating it as a learning score

See how students are using EngE-AI

The Monitor Dashboard gives course staff a view of tutor activity over time, with access to individual chat sessions when closer review is appropriate.

Course staff can:

  • Sort the roster by name or token usage
  • Filter activity to a date range
  • Open available student chat sessions
  • Download a session when there is a course-support need

Use activity as context, not a conclusion. Token usage shows system activity. It does not prove engagement, understanding, effort, or learning.

Student List Management

Student Activity Overview

The student list shows all enrolled students with their token usage. You can sort by:

  • Token Usage: Highest to lowest system activity (default)
  • Alphabetical: By student name

Token usage is an activity signal only. It does not establish engagement, effort, understanding, or learning.

Accessing Student Details

To view detailed student information:

  • Click on any student name to expand their card
  • Open available sessions by title and date
  • Download an individual session only when authorized and necessary
  • See token usage for the selected date range

Student chats are sensitive course records. Use them for legitimate course support and follow institutional privacy practices.
