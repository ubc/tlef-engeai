We help engineering students to solve problems

Consult and practice with EngE-AI. See how you can improve.

Built for how engineers learn

Guided critical thinking, course context, and safeguards — not answer dumps.

Auto-adjusting tone

EngE-AI's memory agent tracks the topics you're struggling with across a conversation and adjusts its tone in response.

Guided pathway

Every message is screened. If a conversation veers towards crisis, harm, or something outside the course, EngE-AI pauses the lesson and responds with real UBC support resources.

Scenario generation

EngE-AI helps instructors create multi-part scenario-based, exam-like questions for students to work through. Students get instant feedback on their answers.

More that helps you practice

  • Diagram creation

    Ask about a process or system and EngE-AI sketches it as a flowchart.

  • Multiple modes

    Manually adjusts the tutor's tone based on students' understanding.

  • Writing feedback for instructors Coming soon

    Instructors will be able to use AI to help review and give feedback on student essays and written work. In development now.

Hosted on UBC's own infrastructure — not sent out to a third party.

Course material, chat history, and student data live in instances that UBC runs and controls. EngE-AI was built to keep UBC community data inside the university's own walls.

Built with UBC students' own investment in teaching.
